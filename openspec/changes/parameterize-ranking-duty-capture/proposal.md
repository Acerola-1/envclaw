## Why

空气质量值守人员已经可以在 Envclaw 中配置浓度排名的业务条件，但现有定时任务仍只保存自然语言提示词，无法确定性地生成与已验证平顶山值守脚本一致的排名截图。

需要将这些业务条件作为结构化入参交给一个可复用的浏览器自动化能力，使定时任务能够生成平顶山市浓度排名截图，同时将数据分析继续留给 API 或 MCP 能力。

## What Changes

- 新增参数化的“浓度排名截图”浏览器自动化能力，支持城市/站点查询、行政区、时间口径、最新或指定时间、污染因子、主题和截图范围。
- 将创建任务页面的浓度排名成果保存为结构化定义，并在任务运行时调用该能力生成截图文件。
- 使用现有 Hermes 定时任务执行链路调用能力；不在脚本或任务定义中保存数智大气账号密码。
- 为能力增加可验证的参数校验、截图范围计算和失败信息。

## Capabilities

### New Capabilities

- `parameterized-ranking-capture`: 根据结构化业务条件生成数智大气浓度排名截图，并交给定时值守任务使用。

### Modified Capabilities

- 无。

## Impact

- `packages/client/src/views/hermes/CreateTask.vue`：保存浓度排名成果定义。
- `packages/server/src`：将结构化任务定义传递给定时执行能力并管理截图产物。
- 新增本地浏览器自动化脚本、参数模式和针对参数映射的测试。
- 依赖现有 Hermes Python/Playwright 运行时；账号凭证通过既有安全配置获取，而不是代码常量。
