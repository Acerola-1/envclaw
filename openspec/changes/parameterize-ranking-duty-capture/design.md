## Context

现有 Hermes 定时任务以提示词为执行载体。浓度排名页面的截图存在确定的页面经验：主题是登录后的全局状态、地图类页面不适合等待网络空闲、截图必须裁切为标题与表格的并集。参考脚本已验证平顶山市日累计截图，但将城市、查询对象、时间、因子和截图范围写死。

本次只处理浓度排名截图；数据分析由平台 API 或 MCP 负责。一张图截图不属于本次变更。

## Goals / Non-Goals

**Goals:**

- 定义稳定、可校验的浓度排名截图配置。
- 用一个参数化 Playwright 脚本替代按城市和条件复制的脚本。
- 让 Envclaw 保存结构化配置，并把截图能力作为 Hermes 定时任务的一部分执行。
- 将凭证与任务配置分离，任务定义和日志不得包含明文密码。

**Non-Goals:**

- 不实现浓度数据分析或文字总结。
- 不实现一张图、红框标记或地图截图。
- 不为每一种参数组合生成新的 Python 源码。
- 不改变数智大气平台的前后端架构。

## Decisions

### 结构化配置作为唯一入参

创建页将浓度排名成果保存为 JSON。运行器通过 JSON 文件或标准输入读取配置，而不是从自然语言提示词反向解析。这样查询对象、地区、时间类型、时间意图、污染因子、主题和截图范围都有可测试的值域。

### 单个能力脚本按配置执行

新增独立的 Python Playwright 运行器。脚本以“确保页面处于目标状态”的方式实现每项配置，而非录制固定点击序列：主题先读取当前状态再切换，条件控件按标签和值选择，截图范围按选项计算。页面结构变化时只维护该能力脚本。

### 凭证通过运行时环境注入

用户名和密码从运行时环境或受保护配置读取；脚本拒绝在缺少凭证时运行。参考脚本中的凭证仅作为页面操作证据，绝不复制到仓库。

### 定时执行显式调用能力

任务提示词包含结构化成果定义及运行指令，Hermes 在任务触发时调用本地能力脚本并把生成文件作为成果。相比依赖模型自行推断网页操作，此方式让网页步骤和参数映射确定。

## Risks / Trade-offs

- [数智大气页面改版导致定位器失效] → 将所有定位器集中在一个能力脚本，并在错误中输出缺失页面状态。
- [指定时间控件的真实交互与页面版本不一致] → 用已登录浏览器实测每个可见控件；无法验证的参数不伪称可用。
- [无人值守登录受到设备数上限影响] → 运行器复用已验证的清退逻辑，并将失败明确返回任务日志。
- [浏览器持续请求使网络空闲永远不成立] → 只等待页面路由、表格和查询结果等具体页面状态。
- [截图文件无法传回 Hermes] → 首版将文件写入任务指定的输出目录，并在任务结果中输出绝对路径；交付通道集成另行实现。
