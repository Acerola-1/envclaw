# 发版完整流程

## 一、更新 hermes-agent 版本（依赖更新）

```bash
# 1. 改版本号
#    编辑 packages/desktop/scripts/runtime-config.mjs
#    DEFAULT_HERMES_VERSION = '0.18.0'  ← 改这里

# 2. 在 Mac 上准备 runtime 包
cd packages/desktop
npm run prepare:runtime
npm run package:runtime

# 3. 在 Windows 上准备 runtime 包（Windows 机器上执行）
cd packages/desktop
npm run prepare:runtime
npm run package:runtime
```

上传到服务器（Mac 和 Windows 产物都放在同一个 tag 目录下，文件名自带平台后缀不会冲突）：

```
Mac 产物（packages/desktop/release/runtime/）：
  hermes-runtime-mac-arm64.json
  hermes-runtime-hermes-agent-0.18.0-mac-arm64.tar.gz
  hermes-runtime-hermes-agent-0.18.0-mac-arm64.tar.gz.sha256
  → /datacenter/claw/hermes-0.18.0-runtime/

Windows 产物（packages/desktop/release/runtime/）：
  hermes-runtime-win-x64.json
  hermes-runtime-hermes-agent-0.18.0-win-x64.tar.gz
  hermes-runtime-hermes-agent-0.18.0-win-x64.tar.gz.sha256
  → /datacenter/claw/hermes-0.18.0-runtime/
```

## 二、更新客户端版本（发版）

```bash
# 1. 改版本号
#    编辑 packages/desktop/package.json
#    "version": "0.7.0"  ← 改这里

# 2. 构建整个项目
cd /Users/acerola/FrontProject/envclaw
npm run build

# 3. 打包客户端（自动包含 write:runtime-release + build）
cd packages/desktop
npm run dist:mac    # Mac
npm run dist:win    # Windows
```

上传到服务器：

```
Mac 产物（packages/desktop/release/）：
  latest-mac.yml
  Claw-X.Y.Z-arm64.dmg
  Claw-X.Y.Z-arm64.dmg.blockmap
  → /datacenter/claw/updates/mac/

Windows 产物（packages/desktop/release/）：
  latest.yml
  Claw-X.Y.Z-x64.exe
  Claw-X.Y.Z-x64.exe.blockmap
  → /datacenter/claw/updates/win/
```

## 三、注意事项

- **服务器先传，再发版**——用户拿到新客户端后立即就要下载 runtime，服务器上必须已有对应目录
- **两个版本号要同步改**——`package.json` 的 `version` 和 `runtime-config.mjs` 的 `DEFAULT_HERMES_VERSION`
- **Mac 只打 arm64**，已配置好，不需要改
- 旧版本目录不用删，老客户端还在用
