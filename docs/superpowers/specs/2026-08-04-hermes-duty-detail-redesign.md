# Hermes 值守任务详情页重构

## 目标

将 `/hermes/duty/:id` (JobDetailPage.vue) 从 Tab 切换布局改为与 `duty-task-detail.html` 原型一致的一页式 2 列 Grid 布局，所有数据来自真实 API。

## 布局

```
┌─ 返回按钮 ────────────────────────────────────────────┐
├─ Hero 卡片 ───────────────────────────────────────────┤
│  任务名称 · 状态Pill                                   │
│  调度：cron · 创建于 date · 由 name 创建               │
│  [立即运行] [暂停/恢复] [编辑] [删除]                    │
├─ 2列 Grid ────────────────────────────────────────────┤
│ ① 任务概况 (KV) │ ② 执行记录 (最近运行列表)           │
├──────────────────┼────────────────────────────────────┤
│ ③ 能力清单       │ ④ 任务操作项 (从 prompt 解析步骤)  │
├──────────────────┴────────────────────────────────────┤
│ ⑤ 成果 (全宽，图片缩略图+文件下载)                    │
└───────────────────────────────────────────────────────┘
```

## 数据来源

| 区域 | 数据 | 来源 |
|------|------|------|
| Hero | 名称/状态/调度/创建者/时间 | `job.*` API |
| 任务概况 | 城市(从prompt解析)/调度/下次运行/推送渠道/成果数量/累计运行/成功率/运行模型/描述 | `job.*` + runs 计算 + prompt 解析 |
| 执行记录 | 最近 5-10 条运行记录（状态/时间/耗时/查看链接） | `listCronRuns()` API |
| 能力清单 | 图标+名称+配置摘要+启用状态 | 现有 manifestOutputs 解析 |
| 任务操作项 | 编号步骤列表 | 从 manifestOutputs 生成或 prompt 解析 |
| 成果 | 图片缩略图 + 文件下载 | 现有 outputArtifacts 逻辑 |

## 关键改动

1. **去掉 Tab 结构** — `<div class="detail-tabs">` 及相关 panel 移除
2. **新增 Hero 卡片** — 匹配原型 `.detail-hero` 样式（flex 左右布局）
3. **执行记录从真实 runs 渲染** — 替换原型静态 HTML，使用 `runs` ref 数据
4. **城市解析** — 正则从 `job.prompt` 匹配城市名称
5. **成果区保留** — 全宽放在 Grid 下方

- `packages/client/src/views/hermes/JobDetailPage.vue` — 重写 template + style，script 增量修改
