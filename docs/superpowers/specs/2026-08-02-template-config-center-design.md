## 1. 背景与动机

现有设计体系已覆盖：工作台首页、值守任务树形列表、任务详情、创建向导（4 种能力配置）、平台管理、智能问数。但缺少一个**系统化的"任务模板"一等公民**——现有 `ScenarioTemplate` 只是 4 个场景占位，没有"可复用、可编辑、可保存"的模板管理机制。

客户实际需求更完整：

1. 系统预置一批**标杆默认模板**（如"平顶山日报推送""臭氧污染简报"），客户可直接使用。
2. 客户可以**克隆默认模板**到"我的模板"后自行编辑。
3. 客户可以**从零自建**模板。
4. 模板由**平台能力（页面功能）组成**，每种能力可自定义配置。
5. 在**智能问数对话中**直接一句话创建值守任务。

本设计补上这个缺口，并统一左侧导航架构，参考 Codex / WorkBuddy 的侧边栏范式。

---

## 2. 产品定位（重新校准）

> **一句话定位**：
> 打开就能用的环保智能管家——以**任务模板**为核心配置中心，客户通过对话/点选/模板克隆三种路径创建值守任务，而非手写提示词。

**核心概念层级**：

```
任务模板 (Template)  ← 可复用配方，本次新增一等公民
    │
    ├─ 模板元信息：名称、描述、来源（系统/自建）
    ├─ 能力清单：一组能力配置（复用 CreateTask 的成果配置）
    │    ├─ 浓度排名：城市=平顶山，指标=[PM2.5, O3]
    │    ├─ 一张图：范围=市级，图层=[AQI]
    │    └─ ...
    ├─ 交付设置：调度频率、推送渠道、执行模型
    └─ 角色基底提示词
    │
    └─ (1:N) 基于模板创建值守任务 (Job)
```

## 3. 左侧导航架构

### 3.1 整体结构

参考 Codex / WorkBuddy 侧边栏范式，左侧导航（~240px）分为**快捷入口区**（固定，永不折叠）和**可折叠内容区**（浏览态）。

```
┌──────────────────────────────┐
│ 🌿 数智大气 · 环保管家         │  ← 品牌
├──────────────────────────────┤
│                              │
│ ┌──────────────────────────┐ │
│ │ [+ 新建对话]             │ │  快捷入口区
│ │ [⏰ 值守任务]             │ │  5 个核心入口
│ │ [📋 任务模板]             │ │  永远可见，无需展开
│ │ [🧩 能力库]               │ │
│ │ [🔗 数据平台]             │ │
│ └──────────────────────────┘ │
│                              │
│ ▼ 历史对话                   │  可折叠
│   平顶山PM2.5分析            │
│   上周趋势对比               │
│   创建日报任务               │
│                              │
│ ▼ 任务空间                   │  可折叠
│   ● 运行中 (3)               │  按状态分组
│     平顶山日报推送           │
│   ◷ 已暂停 (1)               │
│   ◷ 已结束 (2)               │
│                              │
└──────────────────────────────┘
```

### 3.2 快捷入口 vs 折叠区职责

| 区域 | 性质 | 内容 |
|------|------|------|
| 快捷入口 | 操作型，一键直达 | 新建对话、值守任务、任务模板、能力库、数据平台 |
| 历史对话 | 浏览型，按时间倒序 | 历史对话会话列表，点击恢复对话 |
| 任务空间 | 浏览型，按状态分组 | 运行中 / 已暂停 / 已结束，每组可独立折叠 |

### 3.3 折叠交互

- 点击组头（▼ / ▶）切换展开/折叠
- 默认展开最近活跃的组
- 组头右侧显示该组条目数 badge
- 任务空间每行显示状态色点（运行中=绿色脉冲，已暂停=灰色，已结束=绿色实心）

## 6. 对话创建任务交互流（核心创新）

用户在智能问数对话中直接创建值守任务。

### 6.1 完整流程

```
用户输入： "帮我每天早上8点推送平顶山PM2.5数据到企业微信"
    ↓
AI 解析（数智大气对话服务 + 任务字段提取逻辑）
    ↓
AI 回复： "收到，我已为你规划好以下值守任务，确认后即可创建："
    ↓
（在 AI 回复气泡下方内嵌渲染任务摘要卡）
    ↓
┌─────────────────────────────────────────────────────────────────┐
│  📋 拟创建任务                                          [✕]     │
│                                                                 │
│  任务名称    平顶山PM2.5日报推送                                │
│  能力清单    📊 浓度排名（平顶山 · PM2.5 · 实时）               │
│  执行频率    每天 08:00                                         │
│  推送渠道    企业微信                                           │
│  模板来源    自动匹配：系统模板「平顶山日报推送」                 │
│                                                                 │
│  [调整配置 ▸]                      [✓ 确认创建]                │
└─────────────────────────────────────────────────────────────────┘
```

### 6.2 交互要点

- 摘要卡为**内嵌卡片**，非弹窗，在 AI 回复气泡下方直接渲染，可收起（✕）
- **AI 自动匹配模板**：用户描述与系统模板高度吻合时，摘要卡标注模板来源
- **调整配置**：点击后弹出创建向导（预填从对话提取的所有字段），用户逐项微调后保存
- **无匹配模板**：AI 提取字段直接生成配置，不标注模板来源
- **创建结果**：确认后对话区显示"任务已创建，下次执行时间 2026-08-03 08:00" + 状态 pill
- 摘要卡渲染为 Vue 组件，通过 Hermes 对话服务识别"创建任务"意图后触发

## 8. 数据模型

### 8.1 任务模板

```ts
interface TaskTemplate {
  id: string
  name: string
  description: string
  source: 'system' | 'user'      // 来源：system=内置，user=用户自建
  clonedFrom?: string             // 若 user，克隆自哪个系统模板 ID（可空）
  platformType: 'shuzhi' | 'mapairs' | 'national_station' | 'custom'
  capabilities: DutyOutput[]      // 能力清单，复用 CreateTask 的产出配置
  delivery: {
    schedule: string              // cron 表达式
    deliver: string               // 推送渠道（逗号分隔）
    saveLocation?: string
    model?: string
  }
  roleBasePrompt: string
  supplement?: string
  derivedTaskCount: number        // 此模板已创建的任务数
  createdAt: string
  updatedAt: string
}
```

### 8.2 与现有模型的关系

- **TaskTemplate → Job**：N:1（一个模板可创建 N 个任务，一个任务可基于一个模板）
- **TaskTemplate.capabilities → DutyOutput**：1:N，复用现有 CreateTask 能力配置结构
- **DutyOutput → Platform**：N:1，每种能力属于一个平台
- **Job.templateId**：新增字段，记录任务创建时所用的模板 ID
- **系统模板** `source: 'system'` 只读，用户必须通过"克隆"创建 user 副本后才能修改

### 8.3 现有模型适配

| 现有概念 | 本设计中的关系 |
|----------|---------------|
| `Capability`（4 种产出） | 能力清单原子，被模板和任务引用 |
| `ScenarioTemplate` | 保留但降级为"模板分类标签"，模板库使用更细粒度的 `TaskTemplate` |
| `Job` | 新增 `templateId` 可选字段，记录创建来源 |
| `Platform` | 保持不变，平台下可挂接能力定义 |

## 11. 完整用户旅程

### 场景 A：对话创建（首次用户）

```
打开「新建对话」
  → 输入"每天8点推送平顶山PM2.5"
  → AI 匹配系统模板"平顶山日报推送"
  → 弹出摘要卡（标注模板来源）
  → 点击"确认创建"
  → 任务创建成功，出现在「值守任务」运行中组
```

### 场景 B：模板创建（熟悉模板的用户）

```
点击「任务模板」
  → 浏览系统模板
  → 选"平顶山日报推送" → "从本模板创建任务"
  → 创建向导预填全部配置
  → 微调频率为 08:00 / 14:00
  → 创建任务
```

### 场景 C：克隆 + 自建（高级用户）

```
点击「任务模板」→ 系统模板 → 选"平顶山日报推送" → "克隆到我的模板"
  → 编辑：改名称为"周报定制"、增加"监测数据"能力、改频率为每周一
  → 保存模板
  → 基于该模板创建任务（每周执行）
  → 后续可继续克隆该模板创建其他城市任务
```

### 场景 D：从零新建

```
点击「值守任务」→ [+ 新建任务] → "从零新建"
  → 创建向导：选能力（浓度排名+一张图）
  → 逐项配置参数
  → 设频率、渠道
  → 创建任务
```

### 场景 E：任务变模板

```
「值守任务」→ 选中运行良好的任务 → 详情 → "保存为模板"
  → 填写模板名称 → 保存到"我的模板"
  → 后续可从该模板创建更多同类任务
```

## 12. 范围与边界

### 本期包含

- 左侧导航重构：5 快捷入口 + 2 折叠区
- 任务模板系统：模板 CRUD + 编辑页 + 克隆 + 保存为模板

- 新建任务入口选择器
- 模板数据模型 + API

### 本期不包含 / 后续规划

- 模板变量占位符的完整替换引擎（本期支持基础 `{变量}` 语法，克隆时手工替换）
- 模板分享/市场（客户间共享模板）
- 模板版本管理（多版本对比/回滚）
- 模板审核机制（管理员审核用户模板）
- 对话中 AI 意图识别的后端实现（本设计仅定义交互，意图识别与字段提取逻辑由数智大气对话服务团队实现）

### 未决依赖

- 数智大气对话服务是否支持自定义系统提示注入"创建任务意图"识别
- 模板 API 的后端实现（CRUD + 与 Job 的关联字段）
- 模板创建任务时，如何复用到 Hermes Job 的 prompt 组装逻辑
