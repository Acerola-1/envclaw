# 创建值守任务页面重设计

**日期**: 2026-07-29
**状态**: 设计完成
**范围**: `docs/duty-create.html` 视觉与交互重设计（保留 3 步向导框架）

---

## 设计目标

保留现有 3 步向导模式（选择成果 → 设置交付 → 确认任务），在交互范式和视觉风格上彻底重构，实现"温润呼吸感"的感官体验。

### 核心设计原则

- **自上而下自然流**：内容按阅读顺序纵向前进，减少左右视觉跳跃
- **克制留白**：大间距、大圆角、弱阴影，让信息"呼吸"
- **松石绿 + 暖灰**：告别蓝紫科技感，契合环保行业的自然调性
- **内联操作**：配置在成果卡片下方展开，不弹出不跳转

## 一、设计语言体系

### 1.1 色彩

```
底色（宣纸暖白）  #f9f7f4      卡片面（纯白）  #ffffff
文字主色（暖灰）  #3b3a38      文字辅色        #6e6c69
边框（暖灰白）    #e8e4df      分割线          #f0ece7

强调色（松石绿）  #1a8a5a      强调色浅底      #eaf5ef

危险（陶土红）    #c44e3e      危险浅底        #fef4f2
成功（森林绿）    #2e8b5a      信息（湖泊蓝）  #4a8fa8
```

### 1.2 阴影

带暖色调的极浅阴影，替代通用灰黑阴影：

- 卡片：`0 1px 3px rgba(59,58,56,.04), 0 4px 16px rgba(59,58,56,.03)`
- 悬浮：`0 2px 6px rgba(59,58,56,.06), 0 8px 24px rgba(59,58,56,.04)`
- 按钮：`0 2px 8px rgba(26,138,90,.15)`

### 1.3 圆角与间距

- 卡片：`16px`，按钮：`12px`，输入框：`10px`，chip：`20px`
- 卡片内边距：`24-28px`，卡片间距：`20-24px`
- 段落间距：`16-20px`，字段间距：`14-18px`

### 1.4 字体

```css
--font-sans: 'Inter', system-ui, 'PingFang SC', 'Microsoft YaHei', sans-serif;
--font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;
```

- 标题：18-20px / 700
- 正文：14px / 1.6
- 辅助：12px / 1.5

## 二、整体布局

放弃 v1/v2 的固定侧栏 + 内容区双栏结构，改为**全宽沉浸式页面**。

### 2.1 顶部导航栏

- 左侧：返回链接（← 返回值守任务）
- 右侧：页面标题"创建值守任务"
- 分隔用细竖线
- 背景透明，不抢内容注意力

### 2.2 步骤条

- 三个步骤圆点 + 连接线，居中悬浮
- 当前步骤：松石绿渐变圆点 + 发光环
- 已完成步骤：松石绿填充 + 对勾
- 未激活步骤：暖灰边框空心

### 2.3 内容区

- `max-width: 960px` 居中容器
- Step 1：左右两栏（成果列表 `1fr` + 实时预览 `320px`）
- Step 2：单栏卡片网格（2 列）
- Step 3：单栏确认卡片居中

## 三、Step 1：选择成果

### 3.1 任务名称

- 独立白色卡片，16px 圆角
- 输入框暖灰边框，聚焦时松石绿边框 + 浅绿光晕

### 3.2 成果列表

- 每项成果为横向"名片"卡片
- 内容：图标（40px 圆角方块）+ 名称 + 摘要 + 复制/删除按钮
- 默认按钮隐藏，hover 时淡入
- 选中态：左边框松石绿 + 浅绿底色

### 3.3 配置区（内联展开）

- 在选中的成果卡片下方展开，不在右侧面板
- 高度 + 透明度过渡动画展开
- 配置项流式排布，分段控件用 pill 样式
- 因子 chip 激活态：松石绿填充 + 白色文字
- 底部实时摘要行："本次成果：城市排名 · 平顶山市 · 实时 · PM₂.₅/O₃/AQI"

### 3.4 添加成果

- 4 个 pill 按钮：一张图 / 浓度排名 / 小时播报 / 监测数据
- 已添加类型变灰（不可重复添加）
- hover 时图标微弹跳

### 3.5 右侧实时预览

- sticky 定位，白色卡片
- 成果总览：每项成果图标 + 一句话摘要
- 底部小型流程图：获取数据 → 生成成果 → 推送

## 四、Step 2：设置交付

### 4.1 调度时间

- 6 种频率模式排成一行 pill 标签
- 下方统一预览卡片显示具体时间
- 大号时间文字："每天 **09:00**"
- 辅助说明："北京时间 · 预计下次执行 2026-07-30 09:00"

### 4.2 推送渠道

- 单行 pill 选择器：本地 / 企业微信 / 钉钉 / 飞书
- 选中态松石绿底色
- 右侧同行"需要更多渠道？"链接

### 4.3 保存位置 & 运行模型

- 折叠为"高级选项"，点击展开
- 平滑高度过渡动画
- 默认隐藏减少信息密度

### 4.4 底部交付摘要

- 浅色背景行："本次任务将交付 **N** 项成果：浓度排名 · 一张图 · ..."
- 左对齐 + 松石绿强调数字

## 六、动效规范

| 场景 | 动效 |
|------|------|
| 步骤切换 | 面板淡入 + 上移 12px，0.35s ease-out |
| 卡片 hover | 上浮 3px + 阴影加深，0.2s ease-out |
| 按钮点击 | 缩放到 97%，80ms 瞬间反馈 |
| 选中态切换 | 边框颜色 + 背景色渐变，0.25s |
| 配置区展开 | 高度 + 透明度过渡，0.3s cubic-bezier(.4,0,.2,1) |
| Toast | 顶部滑入，3s 后滑出 |
| 确认对勾 | spring 弹入 cubic-bezier(.34,1.56,.64,1) |

- 全局：`@media (prefers-reduced-motion: reduce)` 禁用所有动效

## 七、业务约束

- 4 种成果类型不可重复添加（同类型只能选一次）
- 至少保留 1 项成果
- 成果配置需支持数据驱动的动态表单（配置项随成果类型变化）
- URL 参数支持：`?caps=a,b` 预选成果，`?edit=id` 编辑模式
- 城市/站点数据需级联查询
- 推送渠道列表从后端加载
- 保存位置支持 Electron 原生文件夹选择 + Web fallback
