## 1. 产品概述

### 1.1 一句话定位

UniEcoClaw 是面向环保值守场景的 AI Agent 任务平台,让用户通过对话或模板组合「能力」,自动生成空气质量监测成果并定时推送。

### 1.2 核心概念

| 概念 | 定义 | 来源 |
|------|------|------|
| **平台** | 数据源系统,如数智大气平台、河南省厅、国控站。每个平台提供若干「能力」 | `envclaw_platforms` 表 |
| **能力** | 平台提供的可执行操作,如"一张图截图"、"浓度排名"。是任务的最小组成单元 | `envclaw_platform_functions` 表 |
| **Skill** | 基于 prompt 模板 + 上下文注入的可复用脚本,封装能力的执行逻辑。AI Agent 在创建任务时调用 | `packages/skills/*/SKILL.md` |
| **连接器 (MCP)** | Model Context Protocol 标准服务,让 AI Agent 能调用外部工具和数据源。支持 stdio (本地) 和 HTTP (远程) 两种传输方式 | `studio-mcp-autoinject.ts` |
| **任务** | 由多个能力组合 + 调度规则 + 推送渠道构成的定时值守单元 | `envclaw_jobs` 表 |
| **模板** | 任务的"配方",封装能力组合与配置,支持克隆、分享、导入,实现跨环境复刻 | `envclaw_job_templates` 表 (规划中) |

### 1.3 产品架构

```
用户 → 对话/模板 → AI Agent 调用 Skill → Skill 通过 MCP 连接器访问平台能力
     ↓                                        ↓
  任务调度引擎 → 定时执行 → 生成成果 → 推送到企业微信/钉钉/飞书/邮件
```

## 2. 当前已实现功能

### 2.1 数智大气平台 4 项内置能力

数智大气平台 (`mapairs`, www.mapairs.com) 为系统内置底座,禁止修改或删除。其 4 项能力均以 Skill 形式实现:

| # | 能力名称 | Skill ID | 功能描述 |
|---|----------|----------|----------|
| 1 | 一张图 | `mapairs-onemap-capture` | 使用 Playwright 脚本按结构化参数生成数智大气"一张图"截图,支持地图范围 (全国/省/市)、时间类型 (实时/累计/日)、地图类型 (监测图/插值图)、污染因子、风场、图层等配置 |
| 2 | 浓度排名 | `mapairs-ranking-capture` | 生成城市/站点浓度排名截图,支持查询维度 (城市/站点)、时间类型 (实时/日累计/日/月/年/自定义)、截图颜色 (浅色/深色)、污染因子 (PM₂.₅/PM₁₀/SO₂/NO₂/CO/O₃/AQI)、国标类型配置,附带数据文字总结 |
| 3 | 小时播报 | `mapairs-hourly-brief` | 定位小时播报页面,按行政区、乡镇、污染因子配置截取页面图片,作为定时播报成果推送 |
| 4 | 监测数据 | `mapairs-monitoring-data` | 提取各点位小时/分钟级监测数据,覆盖 PM₂.₅、PM₁₀、AQI、O₃、NO₂、SO₂、CO 等因子,按站点结构化输出 |

> **注**: 后端种子数据 (`platforms.ts:142-146`) 当前含 3 项 (小时播报/浓度排名/数据监测),"一张图"为原型补充,对应真实平台的核心功能,待补入种子数据。

### 2.2 内置 MCP 连接器

系统自动注入 5 个 MCP 服务,无需用户配置:

| 名称 | 传输方式 | 工具数 | 功能 |
|------|----------|--------|------|
| `envclaw-api` | stdio | 12 | 核心 API: 任务管理、模板管理、平台查询 |
| `envclaw-devices` | stdio | 8 | 设备管理: 列表、状态、远程重启 |
| `envclaw-use` | stdio | 5 | 通用工具: 网页搜索、URL 抓取、文件读写 |
| `datacenter-statistics` | HTTP | 15 | 数智大气数据中心统计服务 (Spring AI MCP) |
| `ipp-air-mcp-server` | HTTP | 0 | 数智大气 IPP 空气质量服务 (当前未连接) |

### 2.3 已实现的功能模块

- **对话问数**: 自然语言交互,AI 识别意图并生成任务建议
- **任务创建**: 3 步向导组合能力、配置调度、确认创建
- **任务调度**: 定时执行 (实时/每小时/每天/每周/每月/自定义 Cron)
- **任务管理**: 列表/详情、启停、立即执行、运行记录
- **模板管理**: 浏览、筛选、克隆、编辑、删除 (仅自己的)
- **模板分享**: tar.gz 导出/导入,不含凭证密钥
- **能力看板**: 平台/能力/Skill/MCP 四合一管理
- **Skill 管理**: 启用/禁用、导入 (zip/文件夹)、删除 (仅本地)、详情查看
- **平台接入**: 外部平台接入向导 (OAuth/API Key/账号密码)

## 3. 分阶段功能规划

### 3.1 第一期: 单机桌面版 MVP

**目标**: 实现数智大气平台的完整值守闭环,验证产品核心价值。

| 功能模块 | 功能点 | 优先级 | 状态 |
|----------|--------|--------|------|
| 数智大气登录 | 平台账号登录 (OAuth 2.0),Token 持久化 | P0 | 待实现 |
| 内置能力 | 4 项内置能力全部可执行 (一张图/浓度排名/小时播报/监测数据) | P0 | Skill 已就绪,调度待对接 |
| 任务创建 | 对话创建 + 向导创建双路径 | P0 | 原型已完成 |
| 任务调度 | Cron 调度引擎,支持 6 种频率模式 | P0 | 后端已有 `envclaw_jobs` 表 |
| 成果推送 | 企业微信/钉钉/飞书/邮件/本地 5 渠道 | P0 | 待实现 |
| 模板化配置 | 模板 CRUD + 克隆 + 从模板派生任务 | P1 | 原型已完成,后端表待建 |
| 运行记录 | 执行历史、状态、耗时、成果预览 | P1 | 原型已完成 |
| Skill 管理 | 启用/禁用/导入/删除 | P1 | 后端已实现,前端待对接 |

**交付标准**: 用户能登录数智大气平台,创建值守任务,定时收到推送的空气质量成果。

### 3.2 第二期: 服务器部署 Web 版

**目标**: 从桌面单机版升级为服务器部署的多用户 Web 版,支持团队协作。

| 功能模块 | 功能点 | 优先级 | 说明 |
|----------|--------|--------|------|
| 服务器部署 | Docker 镜像 + docker-compose 一键部署 | P0 | 复用现有 `packages/server` |
| Web 版访问 | 浏览器访问,无需安装客户端 | P0 | Koa + Socket.IO 已就绪 |
| 多用户登录 | 用户注册/登录/权限管理 | P0 | 基于 Hermes Profile 体系 |
| 配置隔离 | 每个用户的任务、模板、对话互不可见 | P0 | `HERMES_WEB_UI_PROFILE` 隔离 |
| 模板分享 | 团队内模板分享,支持覆盖/并存策略 | P1 | tar.gz 导入导出已原型 |
| 运行记录 | 跨用户运行记录聚合 (管理员视角) | P1 | 待设计 |
| 用量统计 | Skill 使用次数、任务执行次数、推送量 | P2 | 后端已有 `getSkillUsageStatsFromDb` |

**交付标准**: 多个用户同时登录 Web 版,各自管理独立的值守任务,互不干扰。

### 3.3 第三期: 多平台与能力扩展

**目标**: 从单一数智大气平台扩展到多平台,支持第三方自主接入,形成能力生态。

| 功能模块 | 功能点 | 优先级 | 说明 |
|----------|--------|--------|------|
| 多平台配置 | 同时接入多个数据平台 (省厅/国控站/水质/噪声) | P0 | `envclaw_platforms` 表已支持 |
| 第三方平台接入 | 平台接入向导,OAuth/API Key/账密三种认证 | P0 | 原型已完成 |
| 第三方 Skill 绑定 | 平台可绑定专属 Skill,接入时自动注册 | P0 | `platforms.skills` 字段已预留 |
| 第三方 MCP 绑定 | 平台可绑定专属 MCP 连接器 | P0 | MCP 管理 API 已实现 |
| 第三方能力绑定 | 平台可绑定自定义能力,映射到分类 | P0 | `envclaw_platform_functions` 表已支持 |
| 能力扩展机制 | 用户可上传自定义 Skill 包 (zip/文件夹),扩展平台能力 | P1 | `importSkill` API 已实现 |
| 零代码接入 | 删掉前端硬编码,改后端 API 动态拉取能力列表 | P1 | 打通 `platform_functions` ↔ 前端 |
| 模板市场 | 公开模板市场,支持评分/克隆次数/使用次数统计 | P2 | `envclaw_template_market` 表 (规划中) |

**交付标准**: 用户能自主接入任意第三方环保平台,绑定专属 Skill 和 MCP,实现零代码能力扩展。

## 4. 功能点详细描述

### 4.1 对话创建任务

**流程**: 用户在对话主页输入自然语言需求 → AI Agent 解析意图,识别需要的能力组合 → 生成参数确认卡片 → 用户确认或修改 → AI 调用 `duty-create.html` 预填能力参数 → 用户在向导中完成调度配置 → 创建任务。

**关键接口**: `POST /api/hermes/chat` (对话流) → `GET /api/envclaw/platforms/:id/functions` (能力列表)

### 4.2 任务向导创建

**3 步流程**:
1. **选择成果**: 添加能力 (一张图/浓度排名/小时播报/监测数据),每项展开配置面板 (行政区、时间类型、因子、截图颜色、国标类型等)
2. **设置推送**: 选择调度频率 (实时/每小时/每天/每周/每月/Cron) + 推送渠道 (企业微信/钉钉/飞书/邮件/本地)
3. **确认任务**: 预览任务名、成果清单、运行计划,点击创建

**保存为模板**: 在确认步骤可点击"保存为模板",跳转模板编辑器并预填当前配置。

### 4.3 任务调度执行

**调度引擎**: 基于 Cron 表达式,支持 6 种预设频率 + 自定义 Cron。任务到期时:
1. 获取最新数据时间点
2. 依次执行各能力对应的 Skill 脚本
3. 收集成果 (截图/数据/文字)
4. 按配置渠道推送给值守人员

**状态管理**: 运行中 / 暂停 / 失败,支持立即执行、启停切换。

### 4.4 模板管理

**模板生命周期**: 创建 → 发布 → 派生任务 → 版本迭代 → 分享/导入

**克隆**: 从现有模板复制一份为"我的"模板,可修改后保存为新版本。

**分享**: 将模板打包为 tar.gz,包含能力配置与调度规则,不含环境凭证。导入时需重新配置推送渠道。

**版本管理**: `envclaw_template_revisions` 表 (规划中) 记录每次修改,支持回滚。

### 4.5 Skill 管理

**Skill 结构**: 每个 Skill 是一个目录,包含 `SKILL.md` (prompt 模板) + 可选的 `references/`、`scripts/` 子目录。

**来源分类**:
- `builtin`: 系统内置 (随版本发布,不可删除,可禁用)
- `hub`: 从 Skill Hub 安装 (不可删除,可禁用)
- `local`: 用户导入 (可删除、可禁用)
- `external`: 挂载外部目录 (只读)

**导入方式**: 上传 zip 包或文件夹 (须含 `SKILL.md`),系统校验名称冲突 (不与 builtin/hub 重名)。

### 4.6 MCP 连接器管理

**管理操作**: 添加 / 编辑 / 删除 / 测试连接 / 重载工具列表 / 启用禁用

**内置服务**: 5 个 (3 stdio + 2 HTTP),由 `studio-mcp-autoinject.ts` 在启动时自动注入到每个 Profile 的 `config.yaml`。

**安全约束**: 内置服务不可删除,用户添加的服务可随时编辑或删除。MCP 名称校验 (非空、无路径分隔符、无控制字符)。

### 4.7 平台接入

**接入流程** (4 步向导):
1. **平台信息**: 名称、类型 (大气/水质/噪声)、官方 URL
2. **认证配置**: OAuth 2.0 / API Key / 账号密码,输入凭证
3. **能力映射**: 选择平台提供的能力,映射到系统分类 (数据采集/数据分析/预警/办公)
4. **测试确认**: 测试连接 + 验证能力 + 完成接入

**内置平台保护**: 数智大气平台为内置底座,禁止修改、禁用或删除。其能力由系统统一维护,所有任务默认可用。
