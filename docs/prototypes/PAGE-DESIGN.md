# UniEcoClaw 原型页面设计文档

> **版本**：v2.0 (2026-08-03)
> **适用范围**：`docs/prototypes/` 下 12 个原型 HTML 页面
> **目标读者**：产品 / UI / 前端开发 / 后端对接 / 评审方
> **配套**：`DESIGN.md`（视觉系统与 CSS 变量）· `PRODUCT-FUNCTION-DESIGN.md`（功能模块规格）· `PAGE-GUIDE.md`（逐页浏览路径参考）

---

## 1. 文档目的

本文档面向 UniEcoClaw 原型定义 **完整的页面清单与信息架构**，覆盖：
- 固定侧栏的统一骨架（4 项导航 + 新建任务主按钮 + 底部用户区）
- 各页面的功能职责、UI 元素组成、交互逻辑与边界条件
- 跨页面的跳转协议（URL 参数 / hash），保证 picker → create、capabilities → create 等关键链路的参数可追溯
- 所有文本与命名的一致性约束：全部可见文本统一用品牌名「UniEcoClaw」；「Skill」汉化「技能」，「MCP」统一称「连接器」；UI 中不使用任何 emoji

---

## 2. 全局骨架：固定侧栏 + 内容区

### 2.1 整体布局

所有 12 个页面共享同一套骨架：

| 区域 | 宽度 / 位置 | 结构 | 是否可滚动 |
|------|-------------|------|-----------|
| 左侧固定侧栏 | 240 px，`position: fixed`，`top:0; bottom:0; left:0` | 自上而下：品牌区 → 主按钮 → 4 项主导航 → 最近对话折叠区 → 底部用户信息 | 最近对话区内可滚动，其余固定 |
| 右侧内容区 | `margin-left: 240px`，自适应剩余宽度 | 页面头部（标题 + 右上角 page-actions 按钮区）→ 筛选/分段 → 内容 → 底部固定操作栏（如有）| 整页可滚动 |

### 2.2 左侧固定侧栏（顺序 & 内容 — 全文最关键约束）

| 顺序 | 区段 | 内容 | 说明 |
|------|------|------|------|
| 1 | 品牌区 | 真实系统 Logo 图标 + 文字「UniEcoClaw」+ 副标「数智环保 · UniEcoClaw」 | 不可点击；所有页面 HTML 必须完全一致 |
| 2 | **主按钮（新建任务）** | 一个高对比度的「新建任务」按钮，链接到 `duty-chat.html` | **永远作为侧栏第一个可操作项**，作为业务用户进入系统的默认起点 |
| 3 | 主导航（4 项） | ①自动化 / ②任务模板库 / ③能力·技能·连接器 / ④更多（折叠） | 与当前页面匹配时高亮 active；对话首页的 4 项均不 active |
| 4 | 最近对话 | 折叠式「最近对话」5 条 + 「查看更多 (N)」按钮 | 折叠状态存 `localStorage.unieco_recent_collapsed` |
| 5 | 用户信息（底部） | 头像 + 姓名 + 通知铃铛 + 设置齿轮；**固定于侧栏底部**（非中间） | 所有页面完全同一段 HTML，禁止漂移到中间 |

### 2.3 主导航 active 规则

- **对话入口**（`duty-chat.html`、`chat-create-task.html`）：4 项主导航都不点亮，主按钮「新建任务」是视觉焦点
- **自动化 3 页**（`duty-tasks.html`、`duty-task-detail.html`、`duty-create.html`）：「自动化」active
- **模板库 3 页**（`templates-library.html`、`template-editor.html`、`template-share.html`）：「任务模板库」active
- **能力·技能·连接器 2 页**（`duty-capabilities.html`、`platform-onboarding.html`）：「能力·技能·连接器」active

## 3. 页面清单与层级

### 3.1 信息架构图

```
UniEcoClaw
├── [主按钮] 新建任务（对话入口，duty-chat.html）
│   └── chat-create-task.html（对话 → 任务完整闭环演示）
│
├── 自动化（duty-tasks.html）
│   ├── 定时任务列表（默认二级 Tab）
│   │   ├── 新建任务 / 从模板·能力·技能·连接器添加（顶部入口 → duty-picker.html）
│   │   ├── 任务详情（duty-task-detail.html）
│   │   └── 创建任务（duty-create.html）
│   │       └── 融合式大提示词 + 技能 / 能力组合 / 连接器多选
│   │
│   └── 运行记录（二级 Tab，默认全折叠）
│       └── L1 任务 → L2 时间点 → L3 执行详情（三层渐进展开）
│
├── 任务模板库（templates-library.html）
│   ├── 筛选条：全部 / 系统 / 我的 / 外部导入（4 种分组，不再有顶部统计卡）
│   ├── 模板编辑器（template-editor.html）
│   └── 模板分享 / 导入（template-share.html）
│
└── 能力·技能·连接器（duty-capabilities.html）
    ├── 平台（方形卡片网格 · 右上角：添加平台）
    │   └── 平台接入向导（platform-onboarding.html）
    ├── 能力（右上角：无按钮 · 12 项能力 + 详情抽屉）
    ├── 技能（右上角：导入技能 · 启用/禁用/删除(仅本地)）
    └── 连接器（右上角：添加连接器 · stdio/HTTP · 工具数/测试）
```

## 4. 页面功能与交互规格

> 说明：每节描述 = **定位 + UI 结构 + 核心交互逻辑 + 特殊边界/约束**

### 4.1 登录页（login.html）

**定位**：用户进入系统的唯一认证入口；**仅保留数智大气平台账号密码登录，不提供本地本地用户体系**。

**UI 结构**：
- 左侧品牌区：真实系统 Logo + 「UniEcoClaw」+ 副标一句话定位
- 右侧登录卡片：平台账号输入框 → 平台密码输入框 → 「登录」按钮 → 「忘记密码」跳平台官网
- 无「本地登录 / 平台登录」切换 Tab

**约束**：
- placeholder 明确写「请输入数智大气平台账号/密码」，避免歧义
- 登录失败 Toast 提示：「账号或密码错误，请使用数智大气平台账号登录」

---

### 4.2 对话·新建任务主页（duty-chat.html）

**定位**：用户默认入口；效仿 Workbuddy 的「大输入框 + 底栏选择器 + 常用能力紧贴框上」布局，把自然语言提问与值守需求描述整合为同一画布，避免对话模块与其他模块设计脱钩。

**UI 结构（自上而下三段式，参考 Workbuddy）**：
1. **顶部空态 Hero（无消息时展示）**：
   - 主标题：**「UniEcoClaw，我帮你」**（已删除原叶子 SVG 图标，标题视觉居中）
   - 副标题：「直接提问，或选一个能力开始 —— 也可以让我把它变成定时运行的值守任务」
   - 场景 Tab：查数据 / 建值守（切换时刷新下方能力 chip 池内容）
   - 示例按钮：「试试：每天早上 8 点把平顶山市的实时浓度排名发到我邮箱」（一键填充）
2. **能力 Chip 行（紧贴输入框正上方，水平可滚动，胶囊按钮）**：
   - 查数据场景：一张图 / 浓度排名 / 小时播报 / 监测数据 / 创建值守任务
   - 建值守场景：创建值守任务 / 定时浓度排名 / 定时一张图 / 定时小时播报 / 定时监测数据
   - 每个 chip：15px 单色 SVG 图标 + 文字；「创建值守任务」chip 用橙色边框区分
3. **大输入框 + 框底工具行 + 框下辅助行（核心交互块）**：
   - **输入框本体**（Workbuddy 风格圆角大框）：16px 内边距，高度随内容扩展，焦点时外发光 + 主色描边
   - **框底工具行**（左右分栏）：
     - 左：`+` 附件/引用文件按钮
     - 右：`模型选择`（Auto / Doubao-Pro / Doubao-Lite / Doubao-Vision / Claude-Sonnet，彩色圆点 + 下箭头 → 向上弹出下拉菜单）→ `语音` → `发送`
   - **框下辅助行**（左对齐）：默认工作空间（下拉）· 完全访问权限（下拉，点击 Toast 示意）
- **消息流（输入后）**：左侧用户气泡 / 右侧 AI 气泡 + 工具调用内嵌卡片 + 任务草稿卡（附「创建为值守任务」跳 create）

**交互逻辑**：
- Enter 发送，Shift+Enter 换行
- 点击能力 chip：一键填充对应 prompt 模板（如 `/一张图` → 完整提示词）并聚焦输入框；`/值守任务` 自动填入建值守示例
- 输入框键入 `/`：在输入框左上弹出 slash 指令浮层（5 项能力），方向键选择、Enter 确认、Esc 关闭
- 模型选择下拉：点击按钮 → 菜单向上展开避免遮挡输入内容；点击其他区域自动关闭；选中项高亮并 Toast 提示「已切换模型：Xxx」
- 任务草稿卡「创建为值守任务」：跳 `duty-create.html?from=chat&prompt=<encoded>` 预填
- 工作空间/权限：下拉点击 Toast 示意（原型阶段不跳转真实设置页）

**视觉约束**：
- 不再在 Hero 中段展示能力 chip（已下移至框上），避免「标题 → 能力 → 输入框」三段式造成视觉断层
- 能力 chip 为胶囊形（999px 圆角），hover 时主色描边+浅底色
- 模型菜单：白底阴影圆角卡片，每项两行（主文模型名+标签/副文定位描述），彩色渐变圆点作模型色标

### 4.3 对话→任务闭环演示（chat-create-task.html）

**定位**：给评审/演示用，展示「对话即任务」的完整链路（非真实发送交互）。

**UI 结构**：
- 消息分步骤渲染，每步配「下一步 ▶」按钮推进
- 关键步骤：用户描述需求 → AI 抽参数 → 生成任务配置卡 → 模拟执行进度 → 成果截图 + 文字总结 → 「查看完整任务详情」跳 duty-task-detail
- 输入框 disabled，并给 banner 提示「本页面为完整闭环演示」

**边界**：
- 演示页按钮不与真实 API 联动，仅做状态机推进

---

### 4.4 自动化主控（duty-tasks.html）

**定位**：值守任务的管理中枢（调度 + 历史记录）。

#### 4.4.1 Tab A：定时任务列表（默认）

**UI 结构**：
- 页面右上角 page-actions：
  - 左侧：「从模板 / 能力 / 技能 / 连接器添加」按钮 → 跳 `duty-picker.html`
  - 右侧：「创建任务」按钮 → 跳 `duty-create.html`
- 筛选条：全部 / 运行中 / 暂停 / 失败 + 搜索（不包含模板筛选）
- 卡片网格：每个卡片 = 任务名 + 调度频率标签 + 上次执行时间 + 状态色带 + **底部 4 按钮横排**：编辑 / 立即运行 / 暂停 / 删除
  - ⚠️ **卡片外层是 `<div>` 而非 `<a>`**，禁止嵌套 `<a>`，避免浏览器剥离内层按钮导致「按钮漂移到卡片外」

**交互逻辑**：
- 点击卡片空白 → 跳任务详情 `duty-task-detail.html?id=xxx`
- 点击底部按钮：`stopPropagation()` 触发对应动作，不跳转
- 新建任务：create 保存成功后跳回本页，新任务卡片插入首位

#### 4.4.2 Tab B：运行记录（**三层渐进展开，默认全折叠**）

**UI 结构（三层必须清晰分组，不能平铺）**：
| 层级 | 展示内容 | 展开方式 |
|------|----------|----------|
| **L1 任务层**（默认全折叠） | 任务名、总执行次数、最后运行时间、状态 | 点击行头 → 展开 L2 时间点列表 |
| **L2 时间点层** | 单次执行的时间戳、耗时、状态、成果数 | 点击 → 展开 L3 单次执行详情 |
| **L3 执行详情** | ①任务摘要 ②生成文件 + 文件夹面包屑导航 ③执行日志 ④「基于本次结果开启专项对话」按钮 | 始终在 L2 内嵌展示，不再另开抽屉 |

**筛选条**：
- 时间范围（今日 / 近 7 天 / 近 30 天 / 自定义）
- 任务名搜索（**不含模板筛选**，因为运行记录与模板无直接关系）
- 状态筛选（成功 / 失败 / 进行中 / 已终止）

### 4.5 任务详情（duty-task-detail.html）

**定位**：单个任务的完整视图，用于巡检配置、排查失败、下载成果。

**UI 结构**：
- 头部：任务名 + 状态徽章 + 调度频率 + 关联模板链接（如有）+ 操作栏（编辑 / 暂停·恢复 / 立即运行 / 删除）
- Tab 切换：配置 / 运行日志 / 成果
- 配置 Tab：能力/技能/连接器清单，每项可展开查看参数；推送渠道；调度规则
- 运行日志 Tab：时间线，每一项可展开查看完整 stdout/stderr
- 成果 Tab：截图预览 + 数据文件下载

**跳转关系**：
- 「编辑」→ `duty-create.html?edit=<jobId>`
- 「另存为模板」→ `template-editor.html?from=detail&id=<jobId>`

---

### 4.6 选择器：从模板·能力·技能·连接器选（duty-picker.html）

**定位**：`create` 流程的前置选择页，用来「组合式复用已有资产」，降低空配置门槛。

**顶部 Tab（4 个，底部操作栏根据 Tab 切换文案）**：

| # | Tab | 多选？ | 底部主按钮 | 特殊 UI 约束 |
|---|-----|--------|------------|--------------|
| 1 | 选模板 | 单选 | 使用此模板创建 → duty-create | 分组 Tab：全部 / 系统 / 我的 / 外部导入；来源标签 T（系统）/ M（我的）/ I（外部导入）**用单字母彩色圆角方块**，不用 emoji |
| 2 | 选能力 | 多选（推荐 ≤ 6） | 使用选中的能力创建 | 按平台分组；卡片**删除彩色小 mono 图标**避免与名称（如「一张图」）重叠；仅保留平台名标签；能力卡片不再含 emoji / 彩色小图 |
| 3 | 选技能 | 多选 | 使用选中的技能创建 | 卡片结构三栏：顶栏左「技能名」右「N 次」胶囊标签；中间描述两行截断；底栏输出标签 + 分类标签；样式对齐「pkr-skill-card」 |
| 4 | 选连接器 | 多选 | 使用选中的连接器创建 | 卡片结构三栏：顶栏左「连接器名」右「stdio/HTTP」颜色徽章；中间描述两行；底栏「N 个工具」+ 分类标签；样式对齐「pkr-mcp-card」 |

**跨页参数协议（关键，实现时必须对齐）**：

```
duty-create.html
  ?from=picker
  &caps=id1,id2                           // 能力 key 数组
  &cap_names=名1|名2                      // URL 编码
  &skills=sk_01,sk_05
  &skill_names=日报技能|PDF技能
  &mcps=mcp_fs,mcp_lark
  &mcp_names=本地文件系统|飞书IM
  &from_template=tpl_xxx                  // 从模板进入时传
```

Picker 初始化：
- hash `#tab=tmpl|caps|skills|mcps` 直接打开对应 Tab，通过 `localStorage.unieco_picker_tab` 记忆上次选择

### 4.7 创建值守任务（duty-create.html）— **融合式大提示词新布局**

**定位**：把「技能 / 连接器 / 能力组合」与「自然语言提示词」放在同一画布上，效仿 Workbuddy 「大提示词框 + 底栏选择器 + 连接器多选」三层次结构，避免用户觉得「技能和连接器是摆设，没有提示词就干不了活」。

**UI 自上而下 6 段**：

1. **顶部 4 张快捷入口卡**（补漏：若用户没走 picker，也能点卡片跳 picker 对应 Tab 预填）：
   - 从模板选 / 选能力组合 / 从技能添加 / 从连接器添加
2. **任务名输入**
3. **大提示词框块**（最核心，视觉占比最大）：

### 4.8 任务模板库（templates-library.html）

**定位**：团队 & 个人的模板资产库；**可分享、可导入、可派生**。

**分组定义（用户之前已确认）**：

| 分组 | 含义 | 可否删除/编辑 |

| **我的** | 自己创建、克隆、重保存、导入后归到我的 | 完全 CRUD |
| 外部导入 | 从 tar.gz 导入后默认落到此分组（可手动移到我的） | 可删除 / 编辑 |

**UI 结构**：
- 页面标题「任务模板库」+ 右上角 page-actions：新建模板 / 分享导入 → template-share
- 分段 Tab：全部 / 系统 / 我的 / 外部导入（带计数）

- **删除顶部 3 个统计卡片**（派生任务数、跨环境分享次数、模板数），避免信息噪声
- 卡片网格（方形卡片为主，展示页基本只负责「展示」，不内嵌太多按钮）：
  - 单字母彩色图标（T/M/I）→ 来源区分
  - 名称 + 说明两行截断
  - 能力/技能/连接器标签组
  - 底部分派任务 / 克隆 / 分享 / 更多（编辑·删除，仅我的）

**交互逻辑**：

## 6. 一致性与边界约束（必须严格执行）

1. **侧栏顺序永不改变**：新建任务主按钮永远在侧栏首位（top 导航区）；用户信息永远在底部；所有页面用同一套 HTML 片段，禁止出现 B 派结构。
2. **品牌名 UniEcoClaw**：所有可见页面标题、brand、登录页、空态 Hero、Toast 中一律使用「UniEcoClaw」。技术文件名 `envclaw-api` 等不变。
3. **Skill 全汉化**：可见文本一律写「技能」，不出现「Skill」字样；MCP 在 UI 中统一称「连接器」，协议名 stdio/HTTP 可保留作为副标签。
4. **零 emoji**：UI 中禁止任何 emoji；图标统一使用 24×24 stroke 风格 inline SVG；分组来源可用单字母圆角方块（T/M/I）。
5. **能力详情抽屉**：禁用半透明/深色背景；`--bg-card` 白底 + 浅灰代码块；与整体黑白墨色基调一致。
6. **禁止 `<a>` 嵌套 `<a>`**：如自动化任务卡片必须用 `<div data-detail>` + click 跳转，避免按钮「漂」出卡片外。
7. **运行记录默认全折叠**：搜索不含「任务模板」筛选；L1→L2→L3 渐进展开，首屏不堆内容。
8. **模板库无顶部统计卡**：模板数、派生任务数、跨环境分享次数 3 项统计卡均不展示。
