### 4.1 对话·新建任务入口

#### 4.1.1 模块目标

把「自然语言提问」和「值守需求描述」变成可执行的即席回答或定时调度任务。业务用户零门槛进入系统，不强迫走模板/能力/技能/连接器前置学习成本。

#### 4.1.2 功能点清单

| # | 功能点 | 说明 | 优先级
|---|--------|------|--------
F-C-01 | 空态 Hero + 场景 Tab（查数据 / 建值守） | 切换场景刷新下方能力 chip 行内容 | P0
F-C-02 | 能力 Chip 行（紧贴输入框上方） | 5 项常用能力快捷填充（一张图/浓度排名/小时播报/监测数据/创建值守任务） | P0
F-C-03 | 大输入框 + 底栏（Workbuddy 风格） | 焦点时外发光；Enter 发送、Shift+Enter 换行；按 `/` 弹 Slash 指令 | P0
F-C-04 | 模型选择（右下底栏下拉） | Auto / Doubao-Pro / Doubao-Lite / Doubao-Vision / Claude-Sonnet 5 选 1；彩色渐变圆点标识；切换后持久化（localStorage） | P1
F-C-05 | Slash 指令浮层 | 5 项能力指令选择（/一张图 / 浓度排名 / 小时播报 / 监测数据 / 值守任务） | P0
F-C-06 | 示例 prompt 一键填充 |「每天 8 点邮件发浓度排名到我邮箱」等 | P1
F-C-07 | 附件 / 语音按钮 | 原型示意（真实接入文件上传 / ASR） | P2
F-C-08 | 意图识别 → 值守草稿卡 | 含「值守/每天/每小时/定时」关键词 → AI 抽参数生成草稿卡（任务名/成果/调度/推送） | P0
F-C-09 | 草稿卡「创建为值守任务」 | 跳 duty-create 预填参数 | P0
F-C-10 | 草稿卡「直接确认（跳过向导）」 | 直接调度并在对话内反馈「已创建·已调度」+ 侧栏定时任务树 +1 | P1
F-C-11 | 工作空间 · 权限等级 | 输入框下一行；权限等级=完全访问（默认）/ 仅读数据 / 仅调用能力（Toast 示意原型） | P2
F-C-12 | 最近对话折叠区 | 侧栏 5 条，可折叠，折叠态存 localStorage | P1

#### 4.1.3 操作流程（主路径 × 2）

路径 A（即席问数）：
> 用户进入 → 场景=查数据 → 点 chip「浓度排名」→ 提示词自动填充 → 改城市名为「郑州」→ Enter 发送 → AI 返回查询结果气泡

路径 B（转值守任务）：
> 用户进入 → 直接输入「每天早上 8 点把平顶山市的实时浓度排名发到我邮箱」→ Enter → AI 抽参数生成草稿卡（推送显示邮件 = 扩展·Hermes 脚本，含安全提示）→ 用户点「创建为值守任务」 → 跳 duty-create，带入 from=chat，prompt 预填 + caps=rank + 调度=每日 08:00 + 推送=邮件

#### 4.1.4 数据归属

| 数据项 | 存储位置 | 归属模块
|--------|----------|--------
最近会话列表与折叠状态 | Web UI 本地（`localStorage`，仅原型；生产放 Web 服务端）| 对话
用户选择的模型偏好 | Web 服务端用户偏好表 | 系统横切
草稿卡参数抽取结果 | Web 服务端（短期缓存 → 落任务表）| 自动化 × 对话

#### 4.1.5 Web 服务端 & Hermes 层对应

| 阶段 | 实现方式
|------|----------
阶段 1（原型 Mock） | 全部前端脚本化，意图用正则 `/值守|每天|每小时|定时/` 识别；参数用固定模板填充
阶段 2（接入 Web UI Server） | `/api/v1/chat/send` → 走 LLM 意图识别 + 参数抽取（函数调用）；返回结构化草稿 JSON
阶段 3（接入 Hermes） | 邮件/扩展项（超出内置模板能力）由 Hermes Agent 编写 & 执行脚本；SMTP 凭证缺失时返回「需补配置」对话气泡 + 补配置引导）

#### 4.2.2 功能点清单

| # | 功能点 | 说明 | 优先级

F-A-11 | 保存为模板展开表单 | 模板名 + 分组 + 描述 + 标签；跳 template-editor 带 URL 参数预填 | P1
F-A-12 | 任务详情 3 Tab | 配置 / 运行日志 / 成果 → 另存为模板 / 编辑 / 暂停 / 立即运行 / 删除 | P0
F-A-13 | 「基于本次运行结果开启专项对话 | 运行记录 L3 → 跳 duty-chat 并注入运行摘要（作为上下文） | P2

#### 4.2.3 核心操作流程（创建值守任务主路径）

> 自动化页 → 点「创建任务」→ 弹出 create → 点顶部快捷入口「选能力组合」→ 跳 picker #tab=caps → 勾选「一张图 + 浓度排名 → 点底部「使用选中的能力创建」→ 回 create 预填 → 大提示词框填入「针对平顶山市早高峰 7:00-9:00 汇总」→ 底栏能力组合 chips 区显示 2 个 chip（×可删 → 连接器勾选「本地文件系统 MCP」（存生成的图存到本地）→ 调度=每天 09:10 → 推送=飞书 → 保存为模板（展开输入模板名「平顶山早高峰汇总」·分组=我的）→ 创建任务 → 返回自动化页，新卡首位插入。

#### 4.2.4 数据归属

| 数据项 | 存储位置 | 归属模块
|--------|----------|--------
定时任务 Job（名称/能力/技能/连接器/调度/推送 | Web 服务端 `jobs` 表 | 自动化
运行记录（L1/L2/L3） | Web 服务端 `job_runs` + `job_run_logs` | 自动化
执行产物（图片/报表/PDF） | Web UI 状态目录 `HERMES_WEB_UI_HOME`/artifacts；Web 服务端对象存储映射 | 自动化 × Hermes
Picker 最后选择 Tab | 前端 `localStorage.unieco_picker_tab` | 对话

#### 4.2.5 权限与状态流转

**任务状态机**：

```
 草稿 → 已调度 ←→ 已暂停
          ↓
      运行中 → 成功 / 失败 / 已终止
          ↑_____重试
```

| 操作 | 角色权限
|---|---
创建 / 编辑自己的任务 | 登录用户
删除系统模板派生出的任务 | 任务创建者 / 管理员
立即运行任何任务 | 任务创建者 / 管理员
查看所有任务 | 本工作空间内所有成员
查看运行日志/成果 | 同上（可配置为仅创建者可见）

#### 4.2.6 Web 服务端 & Hermes 层对应

| 阶段 | Web 服务端 | Hermes 层
|------|-----------|-----------
阶段 1 原型 | 前端脚本生成假数据（job / 定时器模拟调度状态变化 | —
阶段 2 Web UI Server | `/api/v1/jobs` CRUD；`/api/v1/jobs/:id/runs`；Cron 由 node-cron 调度；调用数智大气平台 4 项能力直接平台 API | 暂不触发
阶段 3 完整 | 能力组合 / 技能脚本 / MCP 连接器 → 通过消息队列投递 Hermes；Hermes 执行 → Webhook 回写 run_logs & artifacts | Hermes Agent 负责：技能脚本执行 + MCP 工具调用 + 扩展推送（邮件等缺凭证时要求补全配置）

## 7. 非功能性约束（工程落地红线）

1. **路由薄**：Koa Controller 只做参数校验 + 调用 Service；业务逻辑全部放 Service
2. **状态分离**：Web UI 状态 → `HERMES_WEB_UI_HOME` 或 `HERMES_WEBUI_STATE_DIR`；Hermes Agent 状态独立目录，永不混存
3. **结构化 API**：禁止 shell 字符串拼接；统一 `{cmd, args[]}` 结构化参数数组
4. **本地 API 路由优先**：本地注册路由先于代理 catch-all
5. **用户可见文案 i18n**：所有用户可见新文案 → 多语言文件中添加（不硬编码到模板英）
6. **禁止独立修 bug 不混入无关重构：每条 bug fix atomic commit；原型 HTML 中仅改问题文件
