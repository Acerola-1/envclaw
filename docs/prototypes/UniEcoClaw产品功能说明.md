# UniEcoClaw 产品说明

> **版本**:v0.7(2026-08-02)
> **配套文档**:`docs/prototypes/DESIGN.md`(实现蓝图)

---

## 1. 一句话定位

**Hermes Web UI 是 Hermes Agent 运行时的桌面端总控,围绕"对话即任务"让业务人员、运营和开发者都能在同一个客户端完成 AI 代理的编排、调度、复用和结果回收。**

对标产品:ChatGPT Work(对话优先的协作面板)+ WorkBuddy(任务自动化 + 工作流复用)。

---

## 2. 目标用户与场景

Hermes Web UI 服务三类用户,围绕"**对话即任务**"提供分层能力:

### 2.1 普通人(业务人员 / PM)

**典型场景**:配置每天 9 点的空气质量播报、生成每周客户跟进清单

**路径**:打开客户端 → 跟 Hermes 描述需求 → AI 执行 → 看到结果 → 一键存为定时任务

**用户不需要懂**:prompt engineering、cron 表达式、平台账号配置

### 2.2 业务用户(运营 / 分析师)

**典型场景**:复用团队"周报"模板改个收件人就上线、把郑州日报克隆成洛阳日报

**路径**:打开"常用任务" → 找到团队模板 → 点"克隆" → 改 2-3 个字段(收件人/行政区) → 启用

**用户不需要懂**:数据库、API、Python 脚本

### 2.3 开发者(平台工程师 / 集成商)

**典型场景**:接入新数据源、挂载 Skill/MCP、配置模型供应商

**路径**:打开"能力与平台" → 添加平台 → 4 步向导(基本信息/网址/功能/技能) → 在"常用任务"编辑器里就能引用

**用户需要懂**:平台接口、API 鉴权、prompt 编写

## 3. 核心价值主张

### 3.1 对标 ChatGPT Work + WorkBuddy

| 维度 | ChatGPT Work | WorkBuddy | Hermes Web UI |
|---|---|---|---|
| 入口 | 极简深色侧栏 | 浅色 4 分类入口 | **黑白水墨 4 顶级入口(对话/任务/常用任务/能力与平台)** |
| 主交互 | 对话 + 插件 | 任务 + 自动化 | **对话 + 任务 + 模板复用** |
| 复用机制 | GPTs(需编程) | 模板市场(可视化) | **常用任务库(克隆/分享/导入,零代码)** |
| 扩展性 | 插件系统 | 连接器系统 | **Skill + MCP + 平台接入(三层扩展)** |
| 部署 | SaaS only | SaaS only | **本地 + Web 访问双模式** |

### 3.2 三大独特价值

1. **"对话即任务"闭环**:聊天中识别周期性需求 → 一键落地为值守任务(竞品做不到这么顺)
2. **"模板即复用"机制**:团队经验沉淀为"常用任务",跨设备、跨地域可分享(竞品没有完整的模板市场)
3. **"能力即配置"理念**:Skill/MCP/平台三套扩展机制,开发者不用动核心代码就能接入新数据源

## 4. 当前能力(已交付)

### 4.1 客户端与后端

- **桌面客户端**:Windows / macOS / Linux 三平台 Electron 打包
- **Web 访问**:BFF 服务(端口 8647/8648)支持浏览器访问
- **后端**:Koa + SQLite/PostgreSQL,支持多 Profile(团队隔离)
- **前端**:Vue 3 + Pinia + Naive UI + Vue Router,17+ 路由

### 4.2 核心视图(7 大类)

| 模块 | 视图 | 状态 |
|---|---|---|
| **对话** | ChatView(主交互) | ✅ 已上线 |
| **值守任务** | JobsView(列表) + JobDetail(详情) | ✅ 已上线 |
| **任务创建** | CreateTask(3 步向导) | ✅ 已上线 |
| **能力库** | CapabilityLibrary(嵌在 GuardPanel) | ⚠️ 仅基础 4 项 |
| **推送渠道** | ChannelsView | ✅ 已上线(微信/钉钉/飞书/Telegram/Discord/Slack 等 10+ 平台) |
| **Skill 管理** | SkillsView | ✅ 已上线(profile-scoped) |
| **MCP 管理** | McpManagerView | ✅ 已上线 |

### 4.3 数据平台

- **内置平台**:数智大气(`szdq`,4 项能力:浓度排名/一张图/小时播报/监测数据)
- **外部平台**:后端 `envclaw_platforms` 表支持 14 项 functions(中大平台/省大数据/华东平台)
- **平台账号管理**:加密存储(`.mapairs-credentials.json`),支持多账号

### 4.4 模型与认证

- **预置模型供应商**:(seed-if-absent 模式,首启即用)
- **自定义 Provider**:支持任意 OpenAI 兼容 API
- **API Key 加密存储**:profile-scoped

### 4.5 Profile(团队隔离)机制

- **多 Profile 支持**:`~/.hermes/profiles/{name}/` 目录隔离
- **导出/导入**:`tar.gz` 模式,跨设备迁移
- **每个 Profile 独立**:Skill/MCP/Plugins/Memory/Model/Auth

## 5. 当前短板与改进方向

领导在产品评审会上指出三个核心问题,以下为对应改进方案:

### 5.1 短板 1:换地方无法复刻能力

**问题**:当前能力库只有 4 张静态卡片(其中 2 张被注释),只服务于"数智大气"一个平台。平顶山团队换到郑州/洛阳,**所有能力配置要重新做一遍**。

**改进方案**(M2 完成):
- 新增后端表 `envclaw_job_templates`(模板 CRUD + 版本)
- 新增"常用任务"页(顶级入口)
- 支持模板**克隆**(派生新模板)、**分享**(tar.gz 文件)、**导入**(跨设备/跨团队)
- 任务可追溯来源模板(`Job.template_id` 字段)

### 5.2 短板 2:新能力接入门槛高

**问题**:后端 `envclaw_platform_functions` 表里**有数据**,但 `CreateTask.vue` 的 functions 数组(14 条)却**硬编码在前端**。新增一个平台需要改源码重新发版,做不到"零代码接入"。

**改进方案**(M3 完成):

- 打通 `envclaw_platform_functions` ↔ `CreateTask.vue` 数据流
- 删前端硬编码,改 `GET /api/envclaw/platforms/:id/functions` 拉取
- 新增"数据平台 Hub"页,4 步向导接入新平台
- 接入后,平台功能自动出现在"常用任务"编辑器中

### 5.3 短板 3:Skill / MCP 主入口缺失

**问题**:Skill 和 MCP 目前**藏在"设置"二级菜单**,普通用户根本发现不了。

**改进方案**(M1 + M3 完成):
- M1:解注释侧栏,加 4 顶级入口(对话/任务/常用任务/能力与平台)
- M3:能力库提级为顶级路由,带 onboarding 引导卡片
- Skill / MCP 收纳到"能力与平台"下的二级折叠组(信息架构更清晰)

## 6. 下一阶段

**验收**:聊天 → 点创建任务 → 弹出 CreateTask 向导(预填聊天摘要) → 提交生成 Job

**目标**:开发者零代码接入新数据源,模板编辑器自动出现新平台能力。

- `CapabilitiesView` 顶级路由 + onboarding 引导
- `PlatformsView` 顶级路由 + 4 步接入向导
- 打通 `envclaw_platform_functions` ↔ `CreateTask`
- 8 个新原型 HTML(M3 部分)

**验收**:首次进能力库看到引导卡片;平台 Hub 新接一个数据源后,模板编辑器能引用其功能

### M4:Web 访问能力

- **Web 访问能力**:支持服务器部署、多用户访问

## 7. 使用指南(3 个典型场景)

### 场景 1:PM 配置"每天 9 点空气质量播报"

**操作流程**:
1. 打开 Hermes 桌面客户端
2. 在对话输入框描述需求:"帮我每天早上 9 点查询平顶山空气质量,生成播报推送到企业微信"
3. AI 询问确认后,**聊天末条消息下方**出现"📌 创建为值守任务"按钮
4. 点击按钮 → 进入 CreateTask 向导
5. 步骤 1/3:系统已预选"浓度排名"能力(基于聊天理解)
6. 步骤 2/3:推送目标选"企业微信",频率选"每天 09:00"
7. 步骤 3/3:任务名"平顶山 PM2.5 日报推送",点"创建"
8. 任务自动出现在"值守任务"列表,每天 9 点自动执行

### 场景 2:业务复用"周报"模板

**操作流程**:
1. 打开 Hermes,进入"📋 常用任务"页
2. 在"团队"Tab 找到"郑州空气质量周报"模板
3. 点击卡片,查看模板详情(包含能力清单/调度/推送/历史运行)
4. 点"克隆" → 系统创建新模板"我的周报"
5. 进入编辑器,只改 2 个字段:收件人改成本团队的飞书账号、推送时间从周一 10:00 改成周五 17:00
6. 点"启用" → 任务自动运行
7. 后续可一键"导出 tar.gz"分享给其他团队

### 场景 3:开发者接入新数据源

**操作流程**:
1. 打开 Hermes,进入"⚙️ 能力与平台" → "数据平台"
2. 看到现有平台列表(数智大气/河南省厅/国控站),点"+ 添加平台"
3. 进入 4 步接入向导:
   - **步骤 1 基本信息**:平台名"中大平台"、类型"外部平台"
   - **步骤 2 网址与凭据**:接口地址、操作提示词、账号密码
   - **步骤 3 功能 prompt**:添加"实时监测点位分钟数据流读取"功能,描述 prompt
   - **步骤 4 技能挂载**:勾选"数据采集"
4. 点"完成" → 平台列表新增"中大平台"
5. 进入"📋 常用任务"编辑器,创建任务时**自动出现"中大平台"的功能列表**
6. 任务能直接调用新平台的数据,无需改核心代码

## 8. 技术架构简介

### 8.1 前端

- **框架**:Vue 3(Composition API)+ Pinia(状态管理)
- **UI 库**:Naive UI
- **路由**:Vue Router(`packages/client/src/router/index.ts`)
- **样式**:SCSS + design tokens(色板/圆角/字号)
- **包管理**:pnpm workspace(monorepo)

### 8.2 后端

- **框架**:Koa(轻量 BFF)
- **数据库**:SQLite(`envclaw` 表) + Hermes `state.db`(只读历史)
- **服务分层**:`routes/`(HTTP 入口)→ `controllers/`(请求处理)→ `services/`(业务)→ `db/`(数据)
- **配置管理**:`config-helpers.ts` 提供 `readConfigYamlForProfile` 等
- **进程间通信**:Agent Bridge(与 Hermes Agent 通信)

### 8.3 桌面端

- **框架**:Electron
- **运行时**:Hermes Agent(独立 runtime,~百 MB)
- **自动更新**:从自建镜像服务器下载新版本
- **打包**:`electron-builder` + 镜像分发

### 8.4 部署模式

| 模式 | 适用场景 | 当前状态 |
|---|---|---|
| **本地安装** | 个人/小团队 | ✅ 已支持(Envclaw 桌面端) |
| **服务器部署** | 中大型企业、多用户 | ⏳ 远期规划(M4+) |

## 12. 常见问题(FAQ)

### Q1:新能力怎么接进来?

**答**:本系统采用"声明式 + 4 步向导"接入:

1. 平台开发者实现一个标准的 Function 接口(入参/出参/调用方式)
2. 通过 4 步向导注册到本系统(基本信息/网址/功能/技能)
3. 立即被"常用任务"编辑器引用,无需改核心代码
4. 平台数据自动出现在对话、值守任务、能力库三处

### Q2:领导问"换地方怎么复刻能力"怎么回答?

**答**:本系统提供**三层复用机制**:
1. **常用任务库**:团队经验沉淀为模板,克隆/分享/导入
2. **Profile 机制**:多团队/多地域完全隔离(`tar.gz` 导出导入)
3. **平台级模板**:平台的功能配置可作为模板分享

具体实施在 M2 里程碑。

### Q3:普通用户怎么用?需要懂技术吗?

**答**:不需要。普通用户只需:
- 在对话框描述需求
- 点"创建为值守任务"按钮
- 选推送渠道(像选微信好友一样)
- 改个时间(从下拉菜单选)

高级功能(平台接入/Skill 配置)有"高级"标签,藏在二级菜单,普通用户不会看到。

### Q4:和 ChatGPT / WorkBuddy 的区别?

**答**:三者都是"对话优先 + 任务自动化"模式,本系统独特之处:
- **本地优先**:支持本地安装,数据不外流
- **模板市场**:完整的"克隆/分享/导入"机制
- **三层扩展**:Skill(轻量) + MCP(中量) + 平台接入(重量)
- **多 Profile 隔离**:天然支持多团队/多地域
